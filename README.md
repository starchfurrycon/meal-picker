# 选餐 · meal-picker

说一句「今天想吃什么」，自动比过各平台的价格、优惠与口碑，**只给你最划算的那一份**。

纯前端、零构建、零依赖、可离线运行。数据全部留在你自己的浏览器里。

```
输入一句模糊的话  →  转写成可搜索的关键词  →  并发检索各平台
   →  采集价格 / 折扣 / 券 / 评分 / 口碑  →  按你的偏好加权排名
   →  只呈现第一名：一张卡片，有图、有价、有理由
```

## 数据从哪来（重要，请先读这段）

各平台的价格是**登录态 + 私有接口**的数据。浏览器受同源策略（CORS）限制，
平台也不允许第三方网页直连，加上反爬与风控——**纯前端不可能直接抓到真实价格**。
任何声称能做到的网页，要么在骗你，要么在拿你的账号去撞风控。

所以这个工具把「数据源」做成可插拔的一层，内置两种：

| 数据源 | 说明 |
| --- | --- |
| **内置演示数据源** | 离线可用。用确定性伪随机生成结构完整的占位数据（店名虚构、价格自洽），把整条比价链路真实跑通。**默认使用这个。** |
| **自备数据接口** | 你自己有权访问的接口（自建后端、官方开放平台）。在设置里填入地址即可切换到真实数据。 |

### 自备接口约定

前端会向该地址 `POST` 一个 JSON：

```jsonc
{
  "platform": "meituan",          // 平台 id：jd | meituan | taobao | eleme
  "keywords": ["酸菜鱼", "水煮鱼"], // 转写出的搜索关键词
  "kinds": ["hotpot"],            // 识别出的品类
  "tastes": ["spicy", "value"],   // 口味标签
  "budget": 45,                   // 预算上限，可为 null
  "party": 2,                     // 人数，可为 null
  "avoid": ["香菜"],               // 忌口
  "raw": "想和朋友吃点够味的鱼",     // 用户原话
  "account": "138****"            // 账户脱敏前缀，仅用于你侧鉴权提示
}
```

期望返回一个数组（或 `{ offers: [...] }`）：

```jsonc
[
  {
    "merchant": "川小满小馆",
    "rating": 4.7,
    "reviewCount": 2130,
    "good": [{ "text": "分量是真的足", "tag": "份量足" }],
    "bad":  [{ "text": "等得有点久", "tag": "超时" }],
    "packages": [
      {
        "name": "招牌酸菜鱼套餐",
        "dish": "酸菜鱼",
        "art": "hotpot",          // 可选：插画 id，见 assets/dishes/manifest.json
        "basePrice": 58,
        "shippingFee": 4,
        "packingFee": 1.5,
        "finalPrice": 42.5,        // 可省略，会用原价−优惠+费用推算
        "etaMin": 32,
        "rating": 4.7,
        "reviewCount": 2130,
        "monthlySales": 860,
        "deals": [
          { "kind": "discount", "label": "8.5 折", "amount": 8.7 },
          { "kind": "coupon",   "label": "满 40 减 12", "amount": 12 }
        ]
      }
    ]
  }
]
```

`kind` 可取 `discount | coupon | freeship | member | newcomer`，只影响卡片上的图标与文案。

## 加权比价怎么算

八个因子，权重由你在「设置 → 口味 → 加权偏好」里拖，**自动归一化**，不用凑满 100%：

| 因子 | 默认权重 | 怎么打分 |
| --- | --- | --- |
| 到手价 | 26% | 同批候选里最低价拿满分，区间归一化 |
| 折扣力度 | 18% | (原价 − 到手价) / 原价，55% 折扣封顶 |
| 优惠券 | 12% | 可用券金额；门槛不够会显著降权 |
| 商家评分 | 14% | 3.6 → 5.0 线性映射 |
| 商家诚信 | 10% | 评分 55% + 评价体量 25% + 差评扣分 20% |
| 口味匹配 | 10% | 与关键词/口味标签/品类的命中率 |
| 送达速度 | 6% | 同批候选里最快拿满分 |
| 会员权益 | 4% | 会员价与专属券金额 |

勾选「极致省钱」口味时，价格权重自动 ×1.6、折扣 ×1.2。
另外销量会做 ±2% 的微调（同价位更稳的店略占优）。

**推荐理由不调用大模型**：全部从结构化数据里生成——价格对比、优惠明细、
评分与评价标签、好评原句、时效、诚信度。

## 智能转写（可选）

设置 → 智能转写里填入 OpenAI 兼容接口（Base URL + 模型名 + API Key），
打开开关后，你那句模糊的话会先交给模型转成搜索关键词。

- 模型**只做转写**，不挑店、不报价、不写推荐语——避免它编造价格。
- 提示词极短、强制 JSON、`max_tokens` 卡在 180，输出字段名压到 2 字符。
- 相同的话命中缓存，不会重复计费。
- 结果页脚与设置页会显示本次 token 与**估算花费**（单价自己填，填 0 则不显示）。
- 不开启 / 没配 Key / 接口报错时，自动回退到**内置轻量转写**：完全离线、毫秒级、零成本。

内置转写做的事：品类识别（13 类词典）、口味识别、预算解析（支持「三十块以内」）、
人数、忌口、时段，然后组合出**能真正搜到东西**的关键词。

## 隐私与凭据

- **不明文落盘。** 平台账户与 API Key 经 AES-GCM 256 加密后写入 `localStorage`。
- **不用每次重填。** 默认由设备密钥自动解锁；也可以开启**口令保护**（PBKDF2-SHA256，31 万次迭代），
  此时密钥不落盘，打开需输入口令。
- **导出默认不含密钥**，只有你主动勾选才会带上。
- **一键清除**：设置 → 隐私 → 清除全部本地数据（含设备密钥）。
- 非安全上下文（某些浏览器下 `file://` 没有 WebCrypto）会自动降级为混淆存储，
  并在界面上**明确告知**——这种情况下别填真实密码。

诚实的边界：纯前端工具挡不住同机恶意脚本或能读你本机文件的攻击者。
真正的账号密码，最好别填；必须填就用口令模式。

## 开发

```bash
node scripts/embed-art.mjs    # 把 assets/dishes 的插画内联进 web/js/art-data.js
node scripts/test.mjs         # 纯逻辑冒烟测试（转写/比价/加密/设置），34 项
node scripts/e2e.mjs          # 真实浏览器端到端（CDP），含边界与报错检查
node scripts/e2e-llm.mjs      # LLM 分支（本机假接口，不花钱）
node scripts/build.mjs        # 打包出 dist/
node scripts/e2e-dist.mjs     # 验证 dist 产物在浏览器里可用
```

全部自检都不需要真实 API Key，也不会产生任何费用。


### 设计体系

配色取自插画同一套色板：奶油底 `#FFF7EF`、沙色 `#F0DFC8`、墨棕 `#4A3B2E`、
暖橙 `#FF8A3D`、番茄红 `#E5533D`、奶油黄 `#FFC857`、抹茶绿 `#6FB07F`。
图标是自绘的 24×24 线性图标集（1.7 描边、圆头圆角），插画是 200×200 扁平矢量
（统一 `stroke-width="4"`、统一底座与光晕）。深色模式跟随系统。
