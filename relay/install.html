其实你什么都不用装

选餐默认让中继自己拉起一个浏览器，并把采集器直接注入进去。你只需要在那个窗口里登录一次平台。

正在检测本地中继…

1直接打开选餐

点「开始筛选」时，中继会自动打开一个浏览器窗口，里面已经装好了采集器。

打开选餐

这个浏览器用的是独立配置目录（项目里的 data/browser-profile）， 不碰你日常用的浏览器，也不动你的书签和密码。

2在那个窗口里登录一次平台

  • 在自动打开的平台页面上，用你自己的账号登录 美团、淘宝闪购、京东
  • 登录态会留在这个独立目录里，之后不用反复登
  • 没登录也能采到一部分，但会员价和券会不准

3以后每次都是实时价

每轮比价都会重新打开平台页、重新读一次价格，中继在每轮开始时清空上一轮数据， 不复用任何缓存价格。采到的价格只存在内存里。

想用自己的浏览器？装一次油猴脚本也行

到「设置 → 数据来源 → 采集方式」里选「用我自己的浏览器」， 然后按下面两步装一次。装过就跳过。

  1. 装 Tampermonkey（油猴），四大浏览器都有
  2. 点下面的按钮安装选餐采集器，油猴会弹出安装页面，确认即可
安装采集器脚本

如果点击后是纯文本页面，把地址复制到油猴的「添加新脚本」里，或直接在该页面上点油猴图标的「安装」。

它到底做了什么

  • 监听页面自己发出的搜索请求，读取它返回的 JSON（拦截的是页面与平台之间的通信，不额外发请求）
  • 认不出接口时，退一步读取页面上已经渲染出来的价格文字
  • 把读到的价格 POST 到本机中继 http://127.0.0.1:8765，只存内存，每轮比价开始时清空
  • 不上传任何数据到互联网，不碰你的账号密码，不改动页面上的任何内容
  • 自动模式下的浏览器由中继通过调试端口（只监听本机）注入采集器，中继退出时一起关闭

各平台页面结构随时会变。认不出数据时采集器不会瞎猜，只会如实报告"没读到"。
