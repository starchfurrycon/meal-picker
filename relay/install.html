装一次，之后就不用管了

采集器跑在你自己的浏览器里，用你自己的登录态读各平台真实价格。它不会代替你登录，也不会绕过任何风控。

正在检测本地中继…

1装一个用户脚本管理器

推荐 Tampermonkey（油猴），四大浏览器都有。已经装过就跳过。

前往 Tampermonkey 官网

装完浏览器工具栏上会出现一个黑色小图标。

2安装选餐采集器

点下面的按钮，油猴会弹出安装页面，确认即可。

安装采集器脚本

如果点击后是纯文本页面，把地址复制到油猴的「添加新脚本」里，或直接在该页面上点油猴图标的「安装」。

3在各平台登录一次

  • 在浏览器里打开 美团外卖、淘宝闪购、京东，用你自己的账号登录
  • 登录状态浏览器会自己记住，之后不用反复登
  • 没登录也能采到一部分，但价格、会员价和券会不准

4回到选餐开始比价

之后每次比价，工具会自动打开各平台的搜索页，采集器在那些页面上读价格并回传。

打开选餐

采集完那些标签页会自动关掉。如果浏览器拦了弹出窗口，允许一次就行。

它到底做了什么

  • 监听页面自己发出的搜索请求，读取它返回的 JSON（拦截的是页面与平台之间的通信，不额外发请求）
  • 认不出接口时，退一步读取页面上已经渲染出来的价格文字
  • 把读到的价格 POST 到本机中继 http://127.0.0.1:8765，只存内存，每轮比价开始时清空
  • 不上传任何数据到互联网，不碰你的账号密码，不改动页面上的任何内容

各平台页面结构随时会变。认不出数据时采集器不会瞎猜，只会如实报告"没读到"。
